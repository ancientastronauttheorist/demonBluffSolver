bounded original clear N5 dependency. Rust's
[truth helpers](../../../crates/solver-core/src/validators/helpers.rs) already
separate actual truth from Confessor's apparent truth and preserve exact

resistance suppression, null shared target and actual/copy dispatch order.
Its status application is compatible with the concrete effects here. The
[setup action bridge](../../../crates/solver-core/src/bluff/setup_action_bridge.rs)
supports Confessor callback effects but rejects Tracker, Empath, Shugenja and
ordinary Minion class bindings; its current-data role enum is also narrower
than these five original data roles. That is an explicit unsupported-domain gap, not a silently
accepted wrong full N5 replay. No Rust change or Cargo validation is claimed.

The next composition must take the actual retained N5 initializer output and
carry its source/runtime roles, status storage and continuations into the
actual publication/Init/ordered-Start caller and subsequent acquisition queue.
This separate post-Init audit cannot substitute for that retained state.
All 24 generation-supported copied roles remain an eventual full-domain
obligation; these Hunter/Confessor probes do not reduce that catalogue.
Day request admission, mixed-queue chronology, actual deck/HUD publication,
rendered captures, trusted player-history admission, complete-world comparison
and world/seed weights remain separate gates.
