## Verification and exclusions

Seven new authored regressions cover clear and corrupted-Good dispatch,
repeated null acquisitions with exact ordinals, registerAs clearing, unchanged
state and zero selector draws, exact source/clone identity checks, malformed
Evil/copied/HealthyBluff/role/latch bindings, old-version rejection, absent real
Alchemist schema support, V5 outcome preservation and complete mixed-queue
guards with atomic deferred-callback rejection. Rust syntax formatting and
scoped diff checks passed. Root's release-mode run passed all twelve tests
matching Gemcrafter, including the seven new regressions; all 1,000 library
tests then passed in 20.97 seconds. The first focused run exposed two authored
bridge-fixture assumptions about an absent Start order. Those fixtures now
supply an explicit empty order and test missing/matching-order rejection;
production replay still rejects an absent order. These are development tests,
not a held-out native differential or decision-latency measurement. The release
build also passed. Prior simulation results are retained for unchanged live
behavior; no new simulation campaign is claimed.

The test contexts are authored substitutions supported by original inheritance
and shared native bodies. They are not newly executed retained Gemcrafter
acquisition or original joint-generation witnesses. This change does not
establish support for all twenty-four fallback candidates, original PRNG/path
weights, rendered availability, global phase, legal PlayerHistory, complete
world-set agreement, policy optimality or any full-plan gate. No live solver
bridge consumes this opt-in offline model.
